# PvP Balance Modeling

## Target Combat Behavior

Time-to-kill must remain within controlled range.

Build matchups should form strategic triangles.

No single stat or class should dominate globally.

---

## Power Distribution

Equipment 40%

Stats 35%

Skills 25%

---

## Specialization Rule

Focused stat builds gain 10–20% efficiency advantage.
