# CRUCIBLE — SYSTEMS WIKI

Central reference for Crucible’s game systems: combat, stats, classes, equipment, skills, loot, and balance. Use these pages as the source of truth for design intent and tuning; implementation in code and data should align with them.

**Core pillars:** Server-authoritative real-time combat (60Hz sim / 20Hz broadcast), 8-stat build system with soft caps, class identity (5 classes) + cross-class skill trees (6 trees), template-driven equipment (class vs universal weapons, class-locked armor), and progression (XP, level 1–20, loot, salvage, crafting 3→1).
